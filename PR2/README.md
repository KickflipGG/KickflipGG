# Экзаменационная сессия

## Описание проекта
Веб-приложение для управления экзаменационной сессией в образовательном учреждении. Система предоставляет возможность авторизации, регистрации пользователей с разными ролями (студент, преподаватель, сотрудник деканата) и соответствующий функционал для каждой роли.

## Технологии
- HTML5
- Tailwind CSS
- JavaScript (для базовой функциональности)

## Установка и запуск
1. Клонируйте репозиторий
2. Откройте проект в VS Code
3. Установите необходимые расширения:
   - Live Server
   - GitLens
   - GitHub Pull Requests
4. Запустите проект с помощью Live Server (правый клик на index.html → Open with Live Server)

## Функционал
- Авторизация и регистрация пользователей
- Разграничение прав доступа по ролям:
  - Студент: просмотр расписания, оценок, подача апелляций
  - Преподаватель: управление предметами, внесение оценок, формирование ведомостей
  - Сотрудник деканата: управление расписанием, реестром студентов, отчетностью
- Переключение светлой/тёмной темы
- Адаптивный дизайн для всех устройств
